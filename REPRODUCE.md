# Reproducing AutoTree results

Every performance and accuracy number AutoTree publishes is regenerated by a
script; this repo ships no hard-coded benchmark numbers. This page is the
one-command path from a fresh GPU box to a working tree engine, plus a pointer
to the full benchmark harness.

## 1. Deploy the engine (stock SGLang container + tree overlay)

On a Linux box with an NVIDIA GPU and Docker with the NVIDIA runtime:

```
git clone -b tree-engine https://github.com/RightNow-AI/sglang.git
cd sglang
bash tools/splice/redeploy_container.sh
```

`redeploy_container.sh` recreates the container, applies the tree overlay onto
a stock `lmsysorg/sglang` image, and boots the server on port 30000. To pin the
base image by digest for a fully reproducible build:

```
docker inspect --format '{{index .RepoDigests 0}}' lmsysorg/sglang:latest
```

and substitute that `image@sha256:...` reference in the script.

## 2. Send a tree request and read the envelope

```
curl -s http://127.0.0.1:30000/v1/tree/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"<hf-id>","messages":[{"role":"user","content":"What is 7 times 8?"}],
       "max_tokens":64,"temperature":0.7,"seed":5,
       "tree":{"policy":"beam","branches":4,"budget_tokens":200}}' | python3 -m json.tool
```

The response carries a `tree` object with the per-branch trace
(`tokens_spent_per_branch`, `final_scores`, `pruned_count`, `winner_branch_id`,
`scorer`). See `docs/autotree/api.md` for the full field reference.

## 3. Run the full benchmark

The head-to-head and accuracy tables are produced by the ThoughtBench harness,
which runs the tree / best-of-n / single arms against any OpenAI-compatible
endpoint (AutoTree, vLLM, or SGLang) and emits a results JSON with Wilson
confidence intervals. It lives in the AutoTree reference repo under
`thoughtbench/`; follow its README for the exact configs, seeds, and the
one-command run. Publish the raw per-run logs alongside any number.
